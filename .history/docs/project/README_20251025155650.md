## 🏗️ 项目结构

### 核心目录
```
OpenAIglasses_for_Navigation/
├── app_main.py                 # 主程序入口
├── navigation_master.py        # 导航统领器
├── workflow_blindpath.py       # 盲道导航工作流
├── workflow_crossstreet.py    # 过马路工作流
├── yolomedia.py               # 物品搜索工作流
├── audio_player.py            # 音频播放器
├── bridge_io.py               # 视频流桥接器
├── asr_core.py               # 语音识别核心
├── audio_stream.py            # 音频流处理
├── omni_client.py            # AI对话客户端
├── obstacle_detector_client.py # 障碍物检测客户端
├── trafficlight_detection.py  # 红绿灯检测
├── crosswalk_awareness.py     # 斑马线感知
├── yoloe_backend.py          # YOLO-E后端
├── utils.py                  # 工具函数
├── models.py                 # 数据模型
├── sync_recorder.py          # 同步录制器
├── qwen_extractor.py         # 通义千问提取器
├── qwenturbo_template.py     # 通义千问模板
├── voice/                    # 语音文件目录
├── music/                    # 音乐文件目录
├── static/                   # 静态文件目录
├── templates/                # 模板文件目录
├── compile/                  # 编译文件目录
├── model/                    # 模型文件目录
├── training/                 # 训练脚本目录
├── docs/                     # 文档目录
└── requirements.txt          # 依赖包列表
```

### 功能模块
- **导航系统**: 盲道导航、过马路辅助、物品搜索
- **AI模型**: 深度学习模型集成和推理
- **语音处理**: 语音识别、TTS语音合成
- **视频处理**: 实时视频流处理和AI分析
- **音频处理**: 音频播放、混音、录制
- **Web服务**: FastAPI后端、WebSocket通信
- **前端界面**: HTML/CSS/JavaScript用户界面
