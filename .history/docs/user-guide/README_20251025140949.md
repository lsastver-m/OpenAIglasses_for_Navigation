# 👤 用户手册

## 🎯 系统概述

**OpenAI Glasses for Navigation** 是一款专为视觉障碍用户设计的智能导航辅助系统。通过AI视觉识别、语音交互和实时引导，帮助用户安全、独立地进行日常出行。

## 🚀 快速开始

### 系统启动
1. **硬件连接**: 确保ESP32智能眼镜已正确连接
2. **网络连接**: 检查WiFi连接状态
3. **启动服务**: 运行 `python app_main.py`
4. **访问界面**: 打开浏览器访问 `http://localhost:8081`

### 基本操作
- **语音指令**: 说出"开始导航"启动盲道导航
- **物品查找**: 说出"找物品"进入物品搜索模式
- **对话模式**: 说出"对话"进入AI对话模式

## 🛤️ 盲道导航

### 功能特点
- **实时识别**: 自动检测盲道位置
- **障碍物避让**: 识别并避开障碍物
- **方向引导**: 提供语音方向提示
- **转弯检测**: 自动检测盲道转弯

### 使用步骤
1. **启动导航**: 说出"开始导航"
2. **跟随引导**: 听从语音提示前进
3. **注意障碍**: 系统会自动提醒障碍物
4. **转弯提示**: 接近转弯时会提前提醒

### 语音提示
- **"向前"**: 直行方向
- **"向左"**: 向左调整
- **"向右"**: 向右调整
- **"已对中"**: 方向正确
- **"前方有障碍"**: 发现障碍物

## 🚦 过马路导航

### 功能特点
- **斑马线检测**: 自动识别斑马线
- **方向对齐**: 确保正确过马路方向
- **安全引导**: 提供过马路安全提示
- **红绿灯检测**: 检测交通信号灯状态

### 使用步骤
1. **接近斑马线**: 系统会自动检测
2. **方向对齐**: 听从"已对中"提示
3. **等待信号**: 系统会检测红绿灯
4. **安全过马路**: 按照语音提示过马路

### 语音提示
- **"接近斑马线"**: 发现斑马线
- **"斑马线到了可以过马路"**: 可以过马路
- **"红灯"**: 红灯，请等待
- **"绿灯"**: 绿灯，可以过马路
- **"黄灯"**: 黄灯，注意安全

## 🔧 故障排除

### 常见问题

#### 1. 无法连接设备
**问题**: 设备连接失败
**解决方案**:
- 检查WiFi连接
- 重启设备
- 检查服务器状态

#### 2. 语音识别不准确
**问题**: 语音识别错误
**解决方案**:
- 说话清晰
- 降低环境噪音
- 调整麦克风位置

#### 3. 导航不准确
**问题**: 导航方向错误
**解决方案**:
- 重新校准设备
- 检查摄像头清洁
- 调整检测参数

#### 4. 音频无输出
**问题**: 听不到语音提示
**解决方案**:
- 检查音量设置
- 检查音频设备
- 重启音频服务

## 📚 使用技巧

### 最佳实践
1. **环境选择**: 在光线充足、噪音较小的环境中使用
2. **设备佩戴**: 确保设备佩戴稳定，摄像头清洁
3. **语音清晰**: 说话清晰，语速适中
4. **耐心等待**: 给系统足够时间处理

### 安全提示
1. **注意安全**: 始终注意周围环境安全
2. **备用方案**: 准备传统导航工具作为备用
3. **定期检查**: 定期检查设备状态
4. **及时更新**: 保持系统软件更新

### 维护建议
1. **清洁设备**: 定期清洁摄像头和麦克风
2. **充电管理**: 及时充电，避免电量不足
3. **软件更新**: 定期更新系统软件
4. **备份数据**: 重要数据及时备份
